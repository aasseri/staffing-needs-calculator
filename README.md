# حاسبة الاحتياج الوظيفي

أداة ويب في ملف واحد لتحديد الاحتياج الوظيفي للجهات وفق **الهيكل التنظيمي** ووفق **عبء العمل السنوي**، ومقارنته بالعدد الفعلي للموظفين، ثم إصدار نموذج اعتماد رسمي وتقارير قابلة للطباعة والتصدير إلى Excel.

أُعدّت لإدارة تخطيط الموارد البشرية — الإدارة العامة للموارد البشرية — جامعة الملك خالد.

> **Staffing Needs Calculator** — a single-file, browser-only tool (Arabic, RTL) that estimates staffing needs per organizational unit from the org structure and annual workload hours, compares them with actual headcount from an Excel file, and produces printable approval forms and reports. No server, no build step, no data leaves the browser.

---

## المزايا

- **تحميل الهيكل والموظفين من ملف Excel واحد**: شجرة الهيكل التنظيمي (بالأعمدة أو مُزاحة بالمستويات) وورقة بيانات الموظفين.
- **شجرة جهات قابلة للطي** حسب الجهات الرئيسية، مع **بحث يُظهر الجهة في موقعها** بين الجهات قبلها وبعدها (Enter للنتيجة التالية).
- **تمييز الجهات المُسكّنة على الشجرة** برقم احتياجها عند فتح المشروع، والضغط عليها يفتح تسكينها مباشرة.
- **الاحتياج وفق الهيكل**: أعداد مدير / رئيس قسم / موظف لكل جهة.
- **الاحتياج وفق عبء العمل**: الساعات السنوية ÷ **1023** ساعة للموظف، مقرّبًا للأعلى.
- **حالة الاحتياج**: العدد الفعلي − الاحتياج وفق عبء العمل، **فائض (+) بالأخضر** أو **عجز (−) بالأحمر**.
- **مشروع تسكين**: عدة تسكينات مستقلة (لكل جهة جهاتها وساعاتها وملاحظاتها) تُحفظ في ملف JSON واحد، وتُستكمل لاحقًا مع تحديث الأعداد الفعلية تلقائيًا من ملف Excel الأحدث.
- **نموذج اعتماد رسمي** (A4 بالطول) مع كشف بأسماء الموظفين الحاليين.
- **تقرير الاحتياج** (A4 بالعرض) لكل تسكينات المشروع، مع تفصيل العدد الحالي بالجنس، وتصفية حسب الجهة الرئيسية وحالة الاحتياج، وتصدير Excel منسّق.

## التشغيل

لا يحتاج تثبيتًا ولا خادمًا:

1. افتح `index.html` في **Microsoft Edge** أو **Google Chrome**.
2. اضغط «تحميل ملف الهيكل والبيانات» واختر ملف Excel.
3. اختر الجهات من الشجرة، وأدخل الأعداد والساعات، ثم «حفظ الجهة» أو «اعتماد الاحتياج».

يمكن أيضًا نشرها عبر **GitHub Pages** (Settings ← Pages ← Deploy from branch ← `main` / root)، فتعمل من الرابط مباشرة.

## صيغة ملف Excel

### ورقة الهيكل (أول ورقة ليست ورقة موظفين) — بإحدى صيغتين

| الصيغة | الوصف |
|---|---|
| **بالأعمدة** | أعمدة تُكتشف من أسمائها: «معرف الوحدة»، «اسم الوحدة»، «معرف الوحدة الأم» |
| **مُزاحة** | كل جهة في صف، وموضع العمود هو المستوى (A للجذر، B لما يتبعه، …) |

### ورقة الموظفين (اختيارية)

تُعرف تلقائيًا من عمودي **«رقم الموظف»** و**«جهة العمل الفعلية»**. تُعرض بقية أعمدتها في كشف الأسماء كما هي (عدا «الكادر»)، ويُستخدم عمود **«جنس الموظف (ذكر / أنثى)»** لتفصيل العدد الحالي في التقرير.

يُطابَق اسم «جهة العمل الفعلية» مع أسماء الجهات في الهيكل بعد توحيد الهمزات والتاء المربوطة والتطويل. الموظف الذي لا توجد جهته أو يتكرر اسمها في الهيكل لا يُحسب، ويُذكر عدده في رسالة التحميل.

## ملف المشروع

```json
{
  "app": "kku-staffing-needs-calc", "kind": "project", "format": 7,
  "name": "اسم المشروع",
  "places": [
    { "title": "الجهة الأساسية", "hours": 3069, "notes": "",
      "lines": [ { "path": ["الجذر", "…", "الجهة"], "mgr": 0, "head": 1, "emp": 2 } ] }
  ]
}
```

- الجهات تُحفظ **بمسارها في الهيكل** لا بمعرّف، فتُربط بأي نسخة أحدث من ملف Excel (بالمسار، ثم بالاسم إن كان فريدًا).
- في Edge وChrome يُحفظ المشروع **فوق الملف نفسه** (File System Access API) بعد تأكيد الاستبدال، وفي غيرهما يُنزَّل ملف جديد.

## الخصوصية والأمان

- **كل المعالجة داخل المتصفح.** لا خادم، ولا رفع بيانات، ولا `localStorage`؛ ملف Excel يُقرأ في الذاكرة فقط ويُنسى عند إغلاق الصفحة.
- **لا ترفع بيانات حقيقية إلى المستودع.** ملف `.gitignore` يستثني كل ملفات Excel وملفات المشاريع.
- المكتبات الخارجية تُحمَّل من cdnjs مع **تحقق السلامة (SRI)**:

| المكتبة | الإصدار | الاستخدام |
|---|---|---|
| [SheetJS (xlsx)](https://sheetjs.com) | 0.18.5 | قراءة ملفات Excel وتصدير النموذج المعتمد |
| [ExcelJS](https://github.com/exceljs/exceljs) | 4.4.0 | تصدير التقرير منسّقًا (تُحمَّل عند الطلب فقط) |
| Google Fonts | — | خطا Tajawal وAmiri |

## الطباعة

- في نافذة الطباعة اختر: **الهوامش: افتراضي**، و**المقياس: 100%**، وفعّل **رسومات الخلفية** لتظهر الألوان.
